# ISM3232 - Module 6: OOP for agents chatbot and tool

## Contents
This module contains an assistant that responds to user input with a helpful response. This is a mock chatbot, since it cannot handle user input that is outside of the keywords that are included. An input will go to a human when the input message contains address, payment, or card. These are not handled by the assistant, since it cannot do data entry. If real customer data is used, the assistant might need to use different responses for the data.
